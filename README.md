# RouteWise

RouteWise is an India-only, AI-assisted self-drive road-trip planning platform.

## Setup Instructions

1. Install dependencies for the root, frontend, and backend:
   ```bash
   npm run install:all
   ```

2. Copy `.env.example` files to `.env` in both the `frontend/` and `backend/` directories.

3. Start the development servers:
   ```bash
   npm run dev
   ```

The frontend will start on http://localhost:5173
The backend will start on http://localhost:3000
